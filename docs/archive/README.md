# Archive

This folder contains historical planning, bring-up, and work-log documents.

These documents are preserved as project history. They record design decisions,
hardware debugging, rejected approaches, and lessons learned during development.
They are not needed to build or use Picocalc_Clock, but they may be useful when
investigating hardware behavior or future regressions.

Paths to local reference projects and local log folders have been generalized
where they appeared in the original notes.
